# AgentBox control-plane API (placeholder)

This is where the AgentBox control-plane API lands once the hosted flavor of AgentBox is adopted:
sandbox lifecycle management, workspace leases, and metering for agent runs on Azure Container
Instances. It's expected to be adopted incrementally from the
[NETWORG/AgentBox](https://github.com/NETWORG/AgentBox) prototype, and consumed by the portal in
[`src/portal/`](../portal/).

No application code lives here yet. This directory exists so the target repository layout
(tracked in [issue #32](https://github.com/TALXIS/tools-agentbox/issues/32)) is visible ahead of
that adoption work.
